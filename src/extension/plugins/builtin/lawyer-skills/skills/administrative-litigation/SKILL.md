# 行政诉讼

## 核心要点

### 1. 受案范围
- 可诉：行政处罚/行政强制/行政许可/行政征收征用/行政不作为/行政协议
- 不可诉：国防外交/抽象行政行为/内部行政行为/行政终局裁决/刑事司法行为

### 2. 被告确定
| 情形 | 被告 |
|---|---|
| 直接起诉 | 作出行政行为的机关 |
| 复议后起诉 | 复议机关改变→复议机关；维持→原机关+复议机关 |
| 委托实施 | 委托机关 |
| 临时机构/内设机构 | 组建/设立它的机关 |
| 联合执法 | 共同被告 |

### 3. 举证责任
- 被告举证：行政行为合法性（作出之日起15日内提交证据）
- 原告举证：起诉条件/不作为时证明申请/行政赔偿时证明损害
- 原告可提供被告不利证据，但不免除被告举证义务

### 4. 起诉期限
- 知道行为 + 被告：6个月
- 知道行为但不知被告：1年
- 不知行为内容：不动产20年/其他5年
- 复议前置：先复议再诉讼

### 5. 判决类型
- 维持/驳回原告诉讼请求
- 撤销（重作）/变更/确认违法/确认无效
- 履行法定职责/给付义务
- 赔偿/补偿

## 关键法条
- 《行政诉讼法》《行政复议法》《行政处罚法》
