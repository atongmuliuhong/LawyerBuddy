# 证据整理与分析

## 证据分类（《民诉法》第66条）
| 类型 | 示例 | 证明力 |
|---|---|---|
| 书证 | 合同/函件/公证书/鉴定意见书 | 公文书证>私文书证，鉴定意见>一般书证 |
| 物证 | 侵权物品/损坏物品现场 | 原始物证效力最高 |
| 视听资料 | 录音录像/监控视频 | 需原始载体，不可篡改为前提 |
| 电子数据 | 微信/钉钉/电子邮件/区块链存证 | 需真实性证明，可做司法鉴定 |
| 证人证言 | 证人书面/出庭证言 | 利害关系人证言效力低 |
| 当事人陈述 | 起诉状/答辩状/庭审陈述 | 自认免证 |
| 鉴定意见 | 伤残鉴定/笔迹鉴定/价格评估 | 需质证，可申请重新鉴定 |
| 勘验笔录 | 法院现场勘验记录 | 原始证据 |

## 证据整理步骤
1. **收集**：完整收集相关材料
2. **筛选**：剔除无关/重复/证明力弱的
3. **分类**：按争议焦点分组
4. **编号**：全局统一编号（证据1/证据2/...）
5. **标注**：每份证据标注"原件/复印件/扫描件"
6. **装订**：按顺序装订，每页标注页码
7. **备份**：电子档+纸质档各备份

## 证据链构建
- **三要素**：证据→事实→法律后果
- **闭环原则**：关键事实需多份证据相互印证
- **排除合理怀疑**：刑事案件标准（高）
- **高度盖然性**：民事案件标准（优势证据）

## 证据目录格式
| 编号 | 名称 | 页数 | 证明内容 | 原件/复印件 | 备注 |
|---|---|---|---|---|---|
| 1 | 买卖合同 | 1-5 | 原被告签订合同约定内容 | 原件 | |
| 2 | 银行回单 | 6 | 原告支付预付款 | 复印件 | 原件存银行 |
| 3 | 微信记录 | 7-10 | 被告延迟交货及催告 | 复印件 | 附原始载体 |

## 常见陷阱
- 复印件无原件核对 → 法院可能不采信
- 电子证据无原始载体 → 真实性存疑
- 逾期举证（无正当理由）→ 可能被罚
- 只收集对己方有利的 → 对方也有证据
