# 合同起草

## 通用条款清单

### 必备条款（《民法典》第470条）
1. 当事人的名称/姓名/住所
2. 标的
3. 数量
4. 质量
5. 价款/报酬
6. 履行期限/地点/方式
7. 违约责任
8. 解决争议的方法

### 建议条款
9. 定义条款（关键术语解释）
10. 通知条款（地址/生效方式）
11. 保密条款
12. 知识产权归属
13. 不可抗力
14. 情势变更
15. 可分割性
16. 完整协议
17. 变更与解除
18. 争议解决（管辖/仲裁）

## 常见合同模板要点

| 合同类型 | 特殊关注 |
|---|---|
| 买卖合同 | 标的交付/质量验收/所有权保留/风险转移 |
| 服务合同 | 服务标准/交付物/验收方式/质保期 |
| 委托合同 | 委托权限/转委托/费用承担/委托终止 |
| 租赁合同 | 租赁物使用/维修义务/转租/优先购买权 |
| 融资租赁合同 | 所有权归属/租金构成/期满租赁物处理 |
| 建设工程合同 | 资质/工期/质量/结算/保修 |
| 合伙合同 | 合伙财产/利润分配/风险承担/入伙退伙 |
| 特许经营合同 | 知识产权许可/培训支持/区域保护/费用 |

## 起草原则
- **精确**：避免模糊词（"合理""适当""尽快"）
- **对等**：权利义务双向，禁止单边霸王条款
- **可执行**：违约责任具体（金额/比例/方式）
- **留余地**：不可抗力/情势变更/解除条款
- **可追溯**：变更需书面，通知有送达依据
