# 民事起诉状

## 结构模板
```
民事起诉状

原告：[自然人：姓名/性别/出生日期/住址/身份证号/联系电话]
      [法人/组织：名称/住所地/法定代表人/统一社会信用代码/联系电话]

被告：[同上]

第三人：[如有]

诉讼请求：
1. [请求1：具体/可执行/明确金额]
2. [请求2]
3. [诉讼费用承担]

事实与理由：
一、[事实部分：按时间线陈述，清晰简洁]
二、[理由部分：法律依据 + 论证]

此致
[管辖法院全称]

具状人：[签名/盖章]
日期：[年月日]

附：证据目录（编号/名称/页数/证明内容/原件复印件）
```

## 诉讼请求设计原则
1. **具体明确**：有具体金额/行为/时间，不模糊
2. **可执行**：法院判决后可强制执行
3. **全部主张**：避免遗漏诉讼请求导致另行起诉
4. **金额合理**：过高浪费诉讼费，过低损失利益
5. **顺序合理**：主要请求在前，次要在后

## 事实与理由写作
- **事实**：时间/地点/人物/事件/结果，客观陈述不主观评价
- **证据支撑**：事实陈述后标注证据编号
- **理由**：先引法条，再结合事实论证，逻辑严密
- **语言**：正式但不晦涩，避免情绪化表述

## 管辖选择
- 合同纠纷：被告住所地/合同履行地/约定管辖
- 侵权纠纷：侵权行为地/被告住所地
- 不动产：不动产所在地
- 专属管辖优先于约定管辖
