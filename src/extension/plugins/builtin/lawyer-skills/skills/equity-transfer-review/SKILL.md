# 股权转让审查

## 核心审查维度

### 1. 标的股权合规性
- 股权是否存在：工商登记/出资证明书/股东名册
- 是否质押/冻结/查封：工商查档/执行信息网
- 是否足额出资：实缴/认缴/出资加速到期可能
- 优先购买权：其他股东是否放弃（需书面）
- 章程限制：是否有特别转让限制

### 2. 估值与定价
- 估值方法：净资产法/市盈率法/现金流折现/可比公司
- 定价调整：或有负债/业绩承诺/过渡期损益
- 小股东折价：缺乏控制权的少数股权通常折价20-40%

### 3. 税费分析
| 税种 | 计算 |
|---|---|
| 印花税 | 转让金额 × 0.05%（买卖双方各半） |
| 增值税 | 个人转让上市公司股权免税；企业转让股权按6% |
| 企业所得税 | 转让所得（转让收入-取得成本）× 25% |
| 个人所得税 | 转让所得 × 20% |
| 土地增值税 | 标的公司主要资产为不动产时可能触发（股权转让实质转让不动产） |

### 4. 交割风险
- 股权交割条件：先决条件清单
- 过渡期安排：损益归属/资产负债表基准日
- 或有负债担保：原股东承诺与赔偿机制
- 登记变更：工商变更/章程修改/股东名册更新

### 5. 特别场景
- 对外转让 vs 内部转让
- 股权代持还原
- 离婚分割股权
- 继承股权
- 强制执行股权

## 关键文件
- 股权转让协议
- 股东会决议（同意转让 + 其他股东放弃优先购买权）
- 章程修正案
- 交割确认书
