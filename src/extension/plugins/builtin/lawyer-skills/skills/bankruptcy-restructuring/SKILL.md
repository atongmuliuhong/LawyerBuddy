# 破产与重整

## 程序选择
| 类型 | 适用情形 | 结果 |
|---|---|---|
| 破产清算 | 债务人资不抵债，无重整可能 | 财产拍卖分配，公司注销 |
| 破产重整 | 债务人有挽救可能 | 制定重整计划，恢复经营 |
| 破产和解 | 债务人与债权人达成和解协议 | 按和解协议清偿 |

## 破产申请
- **申请人**：债权人（到期债权）/债务人/股东（出资10%以上）
- **管辖**：债务人住所地法院
- **审查期限**：债权人申请5日内通知债务人，15日内裁定

## 重整程序
### 1. 重整申请
- 直接重整：债权人/债务人/股东
- 清算转重整：法院受理破产后宣告前

### 2. 重整计划
| 内容 | 要求 |
|---|---|
| 债权分类 | 有财产担保/职工/税款/普通/小额 |
| 债权调整 | 各类债权减免比例/延期清偿 |
| 经营方案 | 资产处置/债务重组/股权调整 |
| 执行期限 | 一般不超5年 |

### 3. 债权人会议
- 第一次会议：债权申报期限届满后15日内
- 债权确认/财产变价方案/重整计划草案表决
- 表决：各组过半数+代表债权额2/3以上通过

### 4. 重整效力
- 有财产担保债权人暂停行使权利
- 所有债权人停止个别追偿
- 债务人继续经营（管理人监督）

## 破产清偿顺序
1. 破产费用（诉讼费/管理人报酬/变价费）
2. 共益债务（继续经营产生的债务）
3. 破产人所欠职工工资/医疗/伤残补助/抚恤费用/基本养老保险/基本医疗保险
4. 所欠税款
5. 普通破产债权

## 关键法条
- 《企业破产法》（2006年）
- 《最高院关于适用企业破产法若干问题的规定》(一)(二)(三)(四)(五)
- 《企业破产法司法解释（六）》
