# 商事尽职调查

## 四维尽调框架

### 1. 法律尽调
- 主体资格：工商登记/股权结构/历史沿革/增资/减资
- 资产：不动产/知识产权/重大动产（抵押/质押/查封状态）
- 合同：重大合同（采购/销售/借贷/担保）履行情况与风险
- 诉讼仲裁：在诉/可预见/已判（是否终局/是否执行）
- 合规：环保/劳动/税务/行业许可/资质

### 2. 财务尽调
- 三表分析：资产负债表/利润表/现金流量表（近3年审计报告）
- 资产盘点：货币资金/应收/存货/固定资产真实性
- 负债核查：银行借款/应付/或有负债
- 税务：纳税申报/欠税/税务处罚/税收优惠有效性
- 关联交易：是否公允/是否输送利益

### 3. 业务尽调
- 商业模式：盈利模式/核心竞争力/护城河
- 客户供应商：前五大客户集中度/依赖度/稳定性
- 市场地位：行业排名/市场份额/竞争对手
- 产品服务：核心产品/技术/研发能力/迭代周期
- 团队：核心人员/持股/竞业限制/激励机制

### 4. 合规尽调
- 股权代持：隐名股东协议/实际控制人认定
- VIE架构：是否合规/拆除成本
- 关联交易：定价公允性/是否有利益输送
- 内幕信息：是否涉及上市公司
- 数据合规：个人信息保护/数据出境

## 尽调报告结构
```
1. 项目概览（交易背景/标的简介）
2. 重大风险提示（🔴/🟡/🟢三级）
3. 详细尽调结果（四维分述）
4. 风险解决方案建议
5. 估值调整建议
6. 交易先决条件
7. 附件
```
