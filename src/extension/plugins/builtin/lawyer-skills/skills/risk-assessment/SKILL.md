# 法律风险评估

## 评估框架

### 四维评估矩阵
| 维度 | 评估要点 |
|---|---|
| 合规风险 | 主体资质/行业许可/监管要求/行政处罚 |
| 合同风险 | 条款漏洞/违约责任/履约能力/担保不足 |
| 诉讼风险 | 对方信用/证据充分性/法律适用/管辖不利 |
| 执行风险 | 对方资产/可执行性/转移财产/失信记录 |

### 风险等级
| 等级 | 描述 | 应对 |
|---|---|---|
| 🔴 高 | 可能造成重大损失（>100万）或刑事风险 | 暂缓/否决/需董事会批准 |
| 🟡 中 | 可能造成一定损失（10-100万） | 采取防范措施后可推进 |
| 🟢 低 | 风险可控，损失预期较小 | 正常推进，保持关注 |

## 常见风险点清单

### 合同签订前
- 对方主体资格（工商/注销/吊销）
- 资信状况（失信记录/被执行/行政处罚）
- 核心人员背景（高管失信/犯罪前科）
- 行业资质（是否需特殊许可）

### 合同条款
- 标的描述是否精确
- 价款支付是否有保障（保函/预付款比例）
- 违约责任是否对等
- 终止/解除条件是否清晰
- 争议解决（管辖约定/仲裁条款）

### 履约过程
- 对方履行能力变化（资产查封/经营恶化）
- 我方证据收集（履行记录/通知/催告）
- 时效管理（3年诉讼时效起算点）
- 变更管理（书面确认）

### 争议爆发后
- 保全及时性（诉前保全/诉中保全）
- 证据保全（公证/区块链）
- 执行前调查（对方资产线索）
- 和解可能性评估

## 防范措施
1. **事前**：尽职调查/资信查询/合同审查/担保设置
2. **事中**：履约跟踪/证据留存/风险预警/时效管理
3. **事后**：快速响应/保全执行/谈判和解/损失追偿
