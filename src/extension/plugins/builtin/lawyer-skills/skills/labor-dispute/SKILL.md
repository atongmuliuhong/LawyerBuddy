# 劳动争议

## 适用场景
劳动合同订立/履行/变更/解除/终止引发的争议，含工资福利、社会保险、工伤待遇、竞业限制等。

## 核心要点

### 1. 劳动合同
- 未签合同二倍工资：入职满次月起算，11个月上限（《劳动合同法》第82条）
- 无固定期限合同：连续两次固定期限/满十年/超一年未签书面（第14条）
- 试用期：3年以下≤2月，3年以上≤6月，不得超期

### 2. 工资与经济补偿
- 最低工资标准（各省每年调整）
- 经济补偿：N（满1年支付1月，6月以上不满1年算1年，不满6月算0.5月）
- 违法解除赔偿金：2N
- 代通知金：N+1（三种情形）

### 3. 工伤赔偿
- 认定：单位30日内申请，个人1年内
- 等级：1-10级
- 待遇：医疗费/停工留薪期/伤残补助金/伤残津贴/医疗补助金/就业补助金
- 第三人侵权：双赔（医疗费除外）

### 4. 程序路径
```
协商 → 调解（工会/三方）→ 仲裁（必经）→ 一审 → 二审 → 执行
```
- 仲裁时效：1年，自权利被侵害之日起
- 管辖：劳动合同履行地/用人单位所在地
- 小额终局：不超当地月最低工资12倍，一裁终局（单位可撤，员工可诉）

## 关键法条
- 《劳动合同法》《劳动争议调解仲裁法》《工伤保险条例》
- 《劳动合同法实施条例》《最高院关于审理劳动争议案件适用法律若干问题的解释》(一)(二)(三)(四)
