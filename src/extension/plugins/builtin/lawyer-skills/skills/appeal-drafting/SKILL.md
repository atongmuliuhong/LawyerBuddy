# 上诉状

## 结构模板
```
民事上诉状

上诉人（原审X告）：[信息]
被上诉人（原审X告）：[信息]

上诉人因 [案由] 一案，不服 [一审法院] [一审案号] 判决/裁定，现提起上诉。

上诉请求：
1. 撤销/改判 [一审判决内容]
2. [其他请求]
3. 诉讼费承担

上诉理由：
一、一审判决认定事实错误
[逐条指出事实认定错误，附证据反驳]

二、一审判决适用法律错误
[指出适用法条错误，应适用的法条]

三、一审程序违法
[如有：管辖错误/应当回避未回避/剥夺辩论权/遗漏必要当事人等]

四、新证据
[如有：一审未提交的新证据，说明为何一审未提交]

此致
[二审法院全称]

上诉人：[签名/盖章]
日期：[年月日]
```

## 上诉请求设计
1. **全案改判**：一审事实法律均错误
2. **部分改判**：对一审某一项请求不服
3. **撤销原判发回重审**：一审事实不清/程序违法
4. **增加诉讼请求**：二审新增（调解不成的告知另行起诉）

## 上诉期限
- 判决：15日
- 裁定：10日
- 起算：从收到判决书/裁定书之次日起

## 注意事项
- 上诉必须有具体理由（不能只说"一审错了"）
- 事实错误需用证据反驳
- 法律错误需明确指出应适用的法条
- 二审法院只审理上诉请求范围（例外：一审违反法律强制性规定/侵害他人合法权益）
