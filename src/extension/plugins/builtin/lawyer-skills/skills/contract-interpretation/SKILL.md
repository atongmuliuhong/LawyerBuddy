# 合同条款解释

## 解释方法顺位
《民法典》第142条确立的解释规则：

### 有相对人的意思表示（如合同条款）
1. 文义解释优先（通常理解）
2. 结合相关条款（体系解释）
3. 行为性质与目的（目的解释）
4. 习惯解释（交易习惯/行业惯例）
5. 诚信原则解释

### 无相对人的意思表示（如遗嘱）
1. 文义解释
2. 行为性质与目的
3. 习惯解释
4. 诚信原则

## 漏洞填补
合同未约定/约定不明时的填补规则（《民法典》第510、511条）：

1. 补充协议（协商一致）
2. 按合同相关条款/交易习惯确定
3. 法定填补规则：
   - 价款：订立合同时履行地市场价格/政府定价/指导价
   - 履行期限：随时履行/随时要求履行，合理期限
   - 履行地点：给付货币→接收方所在地；交付不动产→不动产所在地；其他→履行义务方所在地
   - 履行费用：履行义务方负担

## 特殊规则
- **不利解释**：格式条款有两种以上解释的，作出不利于提供格式条款一方的解释
- **不利解释**：对合同起草方不利的解释
- **特别法优先**：法律/行政法规有特别规定的从特别规定
- **手写/打印优先**：手写优先于打印，后写优先于先写
- **明示其一即排除其他**：列举式条款，未列举的排除适用
