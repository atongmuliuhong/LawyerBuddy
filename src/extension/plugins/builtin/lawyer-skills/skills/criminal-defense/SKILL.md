# 刑事辩护

## 阶段划分
```
侦查 → 审查起诉 → 一审 → 二审 → 复核(死刑) → 再审/申诉
```

## 核心辩护方向

### 1. 罪名认定
- 罪与非罪：行为是否符合犯罪构成四要件
- 此罪与彼罪：准确区分易混淆罪名
- 犯罪阶段：既遂/未遂/中止/预备
- 共同犯罪：主犯/从犯/胁从犯/教唆犯

### 2. 证据辩护
- 证据"三性"：真实性/合法性/关联性
- 非法证据排除：刑讯逼供/诱供/程序违法
- 孤证不能定案
- 合理怀疑：排除合理怀疑才能定罪

### 3. 认罪认罚
- 适用条件：自愿 + 如实供述 + 同意量刑建议
- 从宽幅度：一般30%以内，认罪认罚早签可多减
- 值班律师：申请法律援助

### 4. 量刑情节
| 情节 | 效果 |
|---|---|
| 自首 | 可减40%以下，犯罪较轻可减40%以上或免除 |
| 坦白 | 可减20%以下 |
| 立功 | 一般立功减20%以下；重大立功减20-50%，可免除 |
| 赔偿谅解 | 可减20%以下 |
| 初犯偶犯 | 酌情从轻 |
| 前科 | 酌情从重 |

### 5. 程序辩护
- 管辖异议
- 回避申请
- 超期羁押申诉
- 取保/监视居住申请

## 关键法条
- 《刑法》《刑事诉讼法》《律师法》
- 《关于常见犯罪的量刑指导意见》
- 《关于办理刑事案件严格排除非法证据若干问题的规定》
