# 合规审查

## 五维合规框架

### 1. 公司治理
- 股权结构：是否存在代持/隐名股东
- 章程：是否与公司法冲突/是否有特殊限制
- 股东会/董事会运作：决议是否合规/程序是否正当
- 高管任职资格：是否有禁止情形（失信/犯罪记录）
- 关联交易：是否公允/是否有利益输送

### 2. 劳动人事
- 合同：是否全部签订书面合同/是否试用期违规
- 工资：最低工资/加班工资/社保公积金
- 考勤：考勤制度/年休假/产假/病假
- 竞业限制：是否合理/补偿金是否到位
- 裁员：是否符合N+1/是否走民主程序

### 3. 税务合规
- 纳税申报：是否按期申报/是否如实申报
- 税收优惠：是否符合条件/是否有备案
- 发票管理：是否虚开/是否接受虚开
- 股权转让个税：是否代扣代缴
- 特别纳税调整：关联交易定价是否合理

### 4. 数据合规
- 个人信息保护：是否告知同意/是否最小必要
- 数据出境：是否安全评估
- 数据安全：是否加密/是否有备份/是否有应急预案
- 用户权利：是否响应查询/更正/删除请求
- 未成年人：是否有特殊保护

### 5. 行业监管
- 资质许可：是否齐备/是否过期/是否超出范围
- 环保：是否达标排放/是否有环评/是否有处罚
- 安全生产：是否有许可证/是否有培训/是否有事故
- 广告宣传：是否虚假宣传/是否违反广告法
- 反洗钱：是否大额交易报告/是否客户身份识别
