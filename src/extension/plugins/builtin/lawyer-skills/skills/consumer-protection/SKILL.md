# 消费者权益保护

## 三大法律支柱
| 法律 | 核心内容 |
|---|---|
| 《消费者权益保护法》 | 七天无理由/惩罚性赔偿/经营者义务 |
| 《产品质量法》 | 产品责任/缺陷召回 |
| 《食品安全法》 | 十倍赔偿/特别规定 |

## 关键制度

### 1. 七天无理由退货
- 适用：网络/电视/电话/邮购（远程购物）
- 排除：定作/鲜活易腐/在线下载/音像制品/软件/交付的报纸期刊
- 时限：收到商品7日内
- 运费：消费者承担（商品本身无问题）

### 2. 惩罚性赔偿
| 情形 | 赔偿标准 |
|---|---|
| 欺诈（消保法） | 退一赔三（最低500元） |
| 明知商品/服务缺陷仍提供造成人身损害（消保法） | 人身损害赔偿 × 2 |
| 不符合食品安全标准（食安法） | 退一赔十（最低1000元） |
| 生产销售假药劣药 | 退一赔三 |

### 3. 虚假宣传
- 《广告法》第28条：不得虚构商品性能/功效/成分/产地/价格
- 比较广告不得贬低其他经营者商品
- 医疗/保健食品广告严格限制
- 违法处罚：最高20万或违法所得5倍

### 4. 个人信息保护
- 经营者收集使用消费者信息需告知同意
- 不得强制收集非必要信息
- 消费者有权查询/更正/删除个人信息
- 违法处罚：最高5000万或上年营业额5%

## 维权路径
```
与经营者协商 → 消协调解 → 行政投诉（市监/消保）→ 仲裁 → 诉讼
```
- 诉讼时效：3年
- 管辖：被告住所地/合同履行地/侵权行为地
- 举证：初步举证即可，经营者举证免责

## 特别提醒
- 外卖/直播/网购均适用消保法
- 预付卡/充值卡跑路：可报警+民事起诉
- 格式条款（霸王条款）无效：加重消费者责任/减轻经营者义务
