# 律师函起草

## 类型与模板

### 1. 催款类
```
致 [对方全称]：

[委托方] 委托本律师就 [事项] 致函如下：

一、基本事实
[陈述欠款/违约事实，附证据清单]

二、法律依据
[引用法条，《民法典》第xxx条]

三、我方要求
1. 于 [日期] 前支付 [金额] 及利息 [计算方式]
2. [其他要求]

四、法律后果
逾期将采取 [诉讼/仲裁/保全] 等法律措施，届时贵方需承担诉讼费、保全费、律师费等全部费用。

请贵方慎重对待，及时履行义务。

特此函告。

[律师事务所名称]
[律师签名/执业证号]
[日期]
```

### 2. 律师告知函
- 目的：正式通知某事项（如解除合同/主张权利/变更内容）
- 要点：事实清楚、依据充分、后果明确

### 3. 谈判启动函
- 目的：开启协商通道，避免直接对立
- 要点：表达善意 + 阐明立场 + 提出协商方案 + 留有余地

### 4. 声明函/声明书
- 目的：澄清事实/消除影响/制止侵权
- 要点：立场坚定 + 事实清晰 + 警告明确

## 起草原则
1. **格式规范**：抬头/文号/正文/落款齐全
2. **事实清楚**：时间/金额/行为精确，不模糊
3. **依据充分**：法条引用具体，不泛泛而谈
4. **措辞克制**：不挑衅、不扩大矛盾、但态度明确
5. **留有后手**：声明后续法律措施，但不喧宾夺主
6. **送达留痕**：EMS/挂号信/电子邮件均需留底
