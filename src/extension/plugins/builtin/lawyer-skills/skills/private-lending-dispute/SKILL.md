# 民间借贷纠纷

## 适用场景
自然人之间、自然人与法人/其他组织之间、法人/其他组织之间的借款合同纠纷。

## 核心要点

### 1. 借贷合意认定
- 借条/借款协议/欠条
- 聊天记录/录音录像（《民诉法解释》第106条）
- 转账备注（需与其他证据印证）
- 事实推定（转账 + 无其他债权债务关系）

### 2. 本金与利息
- 本金认定：以实际出借金额为准（预扣利息的以到账数为据）
- 利率上限：LPR 四倍（《民间借贷司法解释》第25条，2020.8.20起）
- 逾期利息：约定从约定，无约定按 LPR 1.5 倍
- 逾期罚息/违约金：合计不超过 LPR 四倍

### 3. 担保分析
- 保证人：一般保证/连带保证（未约定视为一般保证，《民法典》第686条）
- 保证期间：有约定从约定，无约定6个月
- 抵押/质押：需登记/交付，未设立则不生效
- 夫妻共同债务：共签/共债共担/家事代理

### 4. 诉讼策略
- 管辖：被告住所地/合同履行地（接受货币一方所在地）
- 时效：3年，自还款期限届满起算
- 证据链：借贷合意 + 款项交付 + 催收记录
- 执行：诉前保全/诉中保全/执行和解/失信被执行人

## 关键法条
- 《民法典》第667-680条、第1064条
- 《最高院关于审理民间借贷案件适用法律若干问题的规定》（2020修正）
- 《民诉法解释》第16-18条（管辖）、第90条（举证责任）
