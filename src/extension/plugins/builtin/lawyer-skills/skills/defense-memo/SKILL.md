# 答辩状

## 结构模板
```
民事答辩状

答辩人（被告）：[信息]
被答辩人（原告）：[信息]

就原告 [姓名/名称] 诉答辩人 [案由] 一案，答辩如下：

答辩意见：
[概括性答辩意见，如：请求驳回原告全部诉讼请求]

一、对原告主张的事实反驳
1. [原告主张1]：反驳
2. [原告主张2]：反驳

二、答辩理由
1. [抗辩事由1：如时效已过/合同无效/免责事由]
2. [抗辩事由2]

三、证据清单

此致
[管辖法院]

答辩人：[签名/盖章]
日期：[年月日]
```

## 抗辩事由类型
| 类型 | 举例 |
|---|---|
| 程序抗辩 | 管辖权异议/时效已过/重复起诉/主体不适格 |
| 实体抗辩 | 合同无效/合同未成立/债务已清偿/抵销/免责 |
| 证据抗辩 | 原告证据不足/孤证不立/非法证据排除 |
| 法律抗辩 | 原告主张适用法律错误/应适用其他规定 |

## 写作要点
- **针对性**：逐条回应原告主张，不遗漏
- **客观性**：用证据说话，避免空泛否认
- **逻辑性**：抗辩事由层层递进，逻辑严密
- **精炼**：突出重点，不拖沓

## 关键规则
- 收到起诉状副本后15日内提交答辩状
- 不提交答辩状不影响法院审理（可当庭答辩）
- 可在答辩中提出反诉（需符合反诉条件）
