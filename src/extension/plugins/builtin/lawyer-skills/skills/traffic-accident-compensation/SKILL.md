# 交通事故赔偿

## 核心要点

### 1. 责任认定
- 交警出具《道路交通事故认定书》（10日内，需鉴定的鉴定结论出来后5日内）
- 复核：收到后3日内向上级交警申请
- 法院可在诉讼中独立认定责任（不完全受交警认定书拘束）

### 2. 保险理赔
- 交强险：2024年新限额（医疗2万/伤残20万/财产4000）
- 商业险：按合同约定，注意免责条款
- 理赔程序：报案→定损→提交材料→赔付
- 代位求偿：对方无责不配合时可申请

### 3. 赔偿项目
| 项目 | 计算方式 |
|---|---|
| 医疗费 | 票据实报实销 + 康复费/整容费/后续治疗费 |
| 误工费 | 误工天数 × 日收入（无固定收入按近3年平均/同行业标准） |
| 护理费 | 护理天数 × 护工标准/亲属误工损失 |
| 交通费 | 实际票据（救护车+复诊+鉴定） |
| 住院伙食补助 | 当地国家机关一般工作人员出差伙食补助标准 |
| 营养费 | 酌情（20-50元/天 × 营养期） |
| 残疾赔偿金 | 受诉法院所在地上一年度城镇居民人均可支配收入 × 伤残赔偿系数 × 年限 |
| 死亡赔偿金 | 同上，年限固定20年（60岁以上递减） |
| 丧葬费 | 受诉法院所在地上一年度职工月平均工资 × 6 |
| 被扶养人生活费 | 人均消费性支出 × 扶养年限 ÷ 扶养人数 |
| 精神损害抚慰金 | 伤残/死亡才有，各省标准不同（河南10级5000，每级增5000，死亡最高5万） |

### 4. 伤残鉴定
- 时机：伤情稳定后（一般出院3-6个月）
- 委托：交警/法院/双方共同委托，单方委托可能不被采信
- 标准：《人体损伤致残程度分级》1-10级

## 关键法条
- 《道路交通安全法》《民法典》第1179条、第1183条
- 《最高院关于审理人身损害赔偿案件适用法律若干问题的解释》
