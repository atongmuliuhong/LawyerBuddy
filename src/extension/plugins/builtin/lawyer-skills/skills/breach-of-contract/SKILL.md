# 违约责任分析

## 归责原则
| 原则 | 适用情形 |
|---|---|
| 过错责任 | 一般侵权/保管合同/委托合同 |
| 无过错责任 | 大部分合同（《民法典》第577条）/危险作业/产品责任 |
| 严格责任 | 违约责任（不要求过错） |

## 违约类型
| 类型 | 定义 | 后果 |
|---|---|---|
| 根本违约 | 不能实现合同目的 | 守约方有权解除 |
| 预期违约 | 履行期限届满前明确/默示不履行 | 守约方可提前请求违约责任 |
| 实际违约 | 履行期内不履行/不适当履行 | 继续履行/采取补救措施/赔偿损失 |
| 迟延履行 | 逾期履行 | 逾期违约金 + 催告后可解除 |

## 责任形式
1. **继续履行**：守约方有权要求履行，但以下除外：法律上/事实上不能履行/履行费用过高/合理期限内未请求
2. **采取补救措施**：修理/更换/重作/退货/减少价款
3. **赔偿损失**：违约造成的损失（直接损失 + 可得利益损失，可预见规则限制）
4. **违约金**：约定优先，过高可请求调减（>30%损失），过低可请求调增
5. **定金**：不得超过20%；违约方双倍返还/守约方没收；与违约金择一

## 免责情形
- **不可抗力**：不能预见/不能避免/不能克服的客观情况（自然灾害/政府行为/社会异常事件）
- **情势变更**：合同成立后客观情况发生重大变化，继续履行显失公平，可请求变更或解除
- **债权人过错**：债权人违约/受领迟延
- **法律特别规定**：如承运人证明货物毁损灭失是因不可抗力/货物自然性质/合理损耗造成
