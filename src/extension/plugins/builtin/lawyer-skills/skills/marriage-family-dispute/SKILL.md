# 婚姻家事纠纷

## 适用场景
离婚、无效婚姻、撤销婚姻、抚养权、抚养费、探望权、夫妻共同财产/债务分割、继承、遗赠扶养协议等。

## 核心要点

### 1. 离婚
- 协议离婚：冷静期30天（《民法典》第1077条）
- 诉讼离婚：法定情形5种（第1079条），首次一般不判离，分居满1年再诉应判离
- 损害赔偿：重婚/与他人同居/家暴/虐待遗弃/其他重大过错（第1091条）

### 2. 抚养权
- 2岁以下：原则归母亲
- 2-8岁：最有利于未成年原则
- 8岁以上：尊重其真实意愿
- 轮流抚养：双方同意 + 不损害子女利益

### 3. 抚养费
- 标准：月收入20-30%，两个以上不超50%
- 期限：至18岁，特殊情况可延长
- 可增加：原定数额不足/子女患病上学/其他正当理由

### 4. 财产分割
- 共同财产：婚后工资奖金/生产经营收益/知识产权收益/继承赠与（遗嘱确定只归一方除外）
- 共同债务：共签/事后追认/用于夫妻共同生活（第1064条）
- 过错方少分：第1087条

### 5. 继承
- 顺序：第一顺序（配偶/子女/父母）→ 第二顺序（兄弟姐妹/祖父母/外祖父母）
- 遗嘱：自书/代书/打印/录音录像/口头/公证，新增打印与录音录像遗嘱
- 特留份：遗嘱应为缺乏劳动能力又无生活来源的继承人保留必要份额

## 关键法条
- 《民法典》婚姻家庭编、继承编
- 《最高院关于适用婚姻家庭编的解释》(一)
