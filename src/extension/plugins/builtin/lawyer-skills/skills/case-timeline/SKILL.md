# 案件时间轴

## 制作框架

### 时间轴结构
```
日期 → 事件 → 证据 → 法律意义 → 备注
```

### 时间轴分层
1. **客观时间轴**：所有相关时间节点（立案/开庭/举证期/上诉期/执行期）
2. **争议焦点时间轴**：围绕争议事实的关键节点（按原告诉讼请求分条）
3. **程序时间轴**：诉讼程序节点（举证期限/开庭/判决/上诉/执行）

## 关键时间节点类型

| 类型 | 典型节点 | 法律意义 |
|---|---|---|
| 签约履行 | 合同签订/付款/发货/验收 | 确定合同履行情况 |
| 违约争议 | 违约行为发生/催告/拒绝履行 | 确定违约责任起点 |
| 权利主张 | 通知/发函/协商记录 | 时效中断/起算 |
| 诉讼程序 | 起诉/受理/送达/举证期/开庭 | 程序节点不可逾越 |
| 鉴定评估 | 鉴定申请/抽签/鉴定/质证 | 关键证据固定 |
| 判决执行 | 一审判决/上诉/二审/执行申请 | 执行依据生效 |

## 制作要求
1. **精确到日**：不确定的标注"约"或"待核实"
2. **证据链接**：每条事实标注证据序号（对应证据目录）
3. **时效预警**：标注即将/已过的时效节点
4. **争议标注**：对双方有争议的事实标注 ⚠️
5. **图表呈现**：按案件阶段（立案→一审→二审→执行）分组

## 格式示例
| 日期 | 事件 | 证据 | 法律意义 |
|---|---|---|---|
| 2025.3.15 | 签订买卖合同 | 证据1：合同 | 合同关系成立 |
| 2025.3.20 | 卖方收到30%预付款 | 证据2：银行回单 | 买方履约 |
| 2025.4.5 | 卖方迟延交货7天 | 证据3：交货单 | 卖方违约 ⚠️争议 |
| 2025.4.12 | 买方催告卖方履约 | 证据4：微信记录 | 催告后违约 |
| 2025.6.10 | 买方起诉 | 立案通知书 | 时效中断 |
