# 法条检索与适用

## 检索路径

### 1. 法律层级
| 层级 | 制定主体 | 效力 |
|---|---|---|
| 宪法 | 全国人大 | 最高 |
| 法律 | 全国人大及其常委会 | |
| 行政法规 | 国务院 | |
| 地方性法规 | 地方人大 | |
| 部门规章 | 国务院部委 | |
| 地方政府规章 | 地方政府 | |
| 司法解释 | 最高法/最高检 | 普遍约束力 |

### 2. 冲突解决规则
1. 上位法优于下位法
2. 特别法优于一般法
3. 新法优于旧法
4. 法不溯及既往（有利溯及除外）
5. 地方性法规 > 部门规章（冲突时由国务院裁决）

### 3. 检索工具推荐
- 裁判文书网：wenshu.court.gov.cn
- 北大法宝/威科/无讼/法信
- 最高院指导性案例（每年两批，2024年已发布41批）
- 公报案例

## 适用分析框架
1. **事实提取**：从案件事实中提取法律要件
2. **法条匹配**：找到对应法条
3. **构成要件分析**：事实是否符合法条构成要件
4. **后果适用**：法条规定的法律后果
5. **例外/但书**：是否存在例外情形
6. **司法解释**：法条的具体适用解释
7. **指导性案例**：相同/相似情形的裁判思路

## 典型适用冲突处理
- **新旧法交替**：看行为发生时有效的法律（法不溯及既往）
- **特别法与一般法**：看法律层级和适用范围
- **司法解释时间**：看司法解释生效时间与行为发生时间
