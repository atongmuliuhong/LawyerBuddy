# 房产纠纷

## 常见类型

### 1. 二手房买卖
- 效力：合同无效情形（无处分权/擅自处分共有/违反政策）
- 定金：不超20%，违约方双倍返还/守约方没收
- 过户：首付/贷款/过户/交房节点衔接
- 违约：逾期付款/逾期交房/拒绝过户
- 税费：谁承担/阴阳合同风险

### 2. 商品房预售
- 合同效力：五证不全→无效（起诉前补齐可有效）
- 面积误差：3%以内据实结算，超出买方可退房
- 逾期交房：违约金约定/解除权（催告后3个月仍未交房可解除）
- 质量问题：主体结构不合格可退房，一般问题维修赔偿
- 产权登记：交房后90日内办理（违约责任）

### 3. 房屋租赁
- 合同形式：6个月以上应书面，否则不定期租赁
- 转租：需出租人同意（有约定从约定）
- 租金：支付期限/逾期违约金
- 押金：租期届满退还，扣除欠租/损坏赔偿
- 提前解除：赔偿损失/押金没收

### 4. 物业管理
- 物业费：业主委员会决定，逾期可诉
- 业主权利：查阅账册/投票权
- 公共部分：收益分配（车位/广告/电梯）
- 维修基金：使用条件/审批程序

### 5. 相邻关系
- 通行权：不动产权利人应为相邻方提供便利
- 采光/通风/排水：不得妨碍
- 噪音/异味：不得造成损害
- 修建/铺设管线：应选择对相邻方损害最小的方式

## 管辖
- 不动产专属管辖：不动产所在地法院
