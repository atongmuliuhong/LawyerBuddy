# 知识产权保护

## 三大权利类型

### 1. 专利（发明/实用新型/外观设计）
- 保护期：发明20年，实用新型10年，外观设计15年
- 侵权判定：全面覆盖原则 + 等同原则 + 禁止反悔原则
- 现有技术抗辩 + 先用权抗辩 + 合法来源抗辩
- 维权路径：行政投诉（市场监管）→ 民事诉讼 → 刑事报案（假冒专利罪）

### 2. 商标
- 保护期：10年，续展每次10年
- 侵权行为：未经许可使用相同/近似商标于相同/类似商品
- 驰名商标保护：跨类保护 + 未注册驰名商标
- 无效/撤销：绝对无效理由（不得作为商标）/相对无效理由（他人在先权利）/连续3年不使用撤销

### 3. 著作权
- 保护期：作者终生+50年；法人/组织首次发表后50年
- 侵权行为：复制/发行/传播/改编/出租/展览等
- 合理使用：个人学习/评论/新闻报道/教学科研等
- 避风港原则：通知+删除，平台免责

## 维权策略
1. 保全证据（公证/区块链存证）
2. 发函/协商
3. 行政投诉/电商平台投诉
4. 诉前禁令 + 财产保全
5. 起诉：停止侵权 + 赔偿（实际损失/侵权获利/法定赔偿最高500万）+ 赔礼道歉
